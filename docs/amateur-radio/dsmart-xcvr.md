# DSMART-XCVR

!!! note "Source"
    Mirrored from [DSMART-XCVR](https://dallasmakerspace.org/wiki/DSMART-XCVR) on the Dallas Makerspace wiki (CC BY-SA 3.0).

The DSMART Transceiver is an open sourced hardware and software Smart Amateur Radio terminal. The reference design includes:

- 720MHz super-scalar ARM Cortex-A8 (armv7a)
- 3D graphics accelerator
- ARM Cortex-M3 for power management
- 2x Programmable Realtime Unit 32-bit RISC CPUs
- microSD card slot
- Android 4.2
