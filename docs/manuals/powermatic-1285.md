[![](https://dallasmakerspace.org/w/images/thumb/c/c5/20150608_023829.jpg/300px-20150608_023829.jpg)](https://dallasmakerspace.org/wiki/File:20150608_023829.jpg) [](https://dallasmakerspace.org/wiki/File:20150608_023829.jpg)Powermatic Model 1285

A jointer is used to true a face of a board. A jointer alone cannot be used to make a board of even thickness. For this task, a thickness planer is used. Training is required in order to use this machine. **NO ENDGRAIN ON THIS MACHINE.**
