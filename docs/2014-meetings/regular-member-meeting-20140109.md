### Members Running Meetings (Pearce Dunlap)

Problem: Attempting to change who will be running the membership meeting on short notice (the day of if not less than 8-10 hours before) has become an issue.

Solution: It has been offered to allow a non-board member to run the membership meeting. If a member would like to run the next membership meeting they should ask to do so by placing it on the agenda, preferably in the "New items" section or in the "Discussion Items" if they missed the deadline.

Example: During the 2/13/14 meeting Tyler D. adds "I would like to run the 3/13/14 membership meeting." If no one objects then Tyler D. gets to run the meeting.
