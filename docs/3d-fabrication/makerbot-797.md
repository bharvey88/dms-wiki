- [Reprap Motherboard v1.2](http://reprap.org/wiki/Motherboard_1.2), Reprap Generation 3 electronics
- [Extruder Controller v2.2](http://reprap.org/wiki/Extruder_Controller_2.2), Reprap Generation 3 electronics
- [(Heater) Relay Board v1.0](http://wiki.makerbot.com/rb1)
- Plastruder MK6
  - [Stepper Motor Driver v3.3](http://wiki.makerbot.com/thingomatic-doc:stepper-driver-3-3) -- [Install doc](http://wiki.makerbot.com/stepstruder-mk6-with-gen3)
- Opto Endstops (non-functional at this time)
- 1 Non-heated build platform countersunk screws
- 1 Non-heated build platform non-countersunk screws
- 1 Heated build platform

### Software Settings Notes

- X Backlash is currently 0.1mm
- Y Backlash is currently 0.11mm *Note that the Y belt may need to be tightened to maximum tension from time to time*
- Optimal PLA temp is 205C
- Optimal ABS temp is 220C
