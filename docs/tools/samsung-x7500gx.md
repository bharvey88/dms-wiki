# Samsung X7500GX

!!! note "Source"
    Mirrored from [Samsung X7500GX](https://dallasmakerspace.org/wiki/Samsung_X7500GX) on the Dallas Makerspace wiki (CC BY-SA 3.0).

Rates noted on the [Printers](../dallas-makerspace/printers.md) page.

This is the MFP currently (7/19/2017) on lease for making copies, prints, etc. It was specifically brought in for making the Handbook booklets, but can be used for anything, as well.

Here's how to get to it:

- \\PRDC1\DMS Copier

This should also be posted on the side of it, but I'm always looking to have this info "online" as well, because I like to be able to find the process whilst planning, rather than hoping it's still posted on the side and driving over...

Alternately**, there is also a direct to printer mode that works well, but has limited formats (easiest is convert to pdf for printing).**

- In the URL type in 192.168.200.70, a pop up screen will appear.
- In the upper Right Hand quadrant there are some tabs, select Direct Print
- Make sure it's on COLOR if you want it
- Select your file
- Print
