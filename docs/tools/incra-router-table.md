# Incra Router Table

!!! note "Source"

[![](https://dallasmakerspace.org/w/images/thumb/8/8e/INCRA-router.jpg/300px-INCRA-router.jpg)](https://dallasmakerspace.org/wiki/File:INCRA-router.jpg) [](https://dallasmakerspace.org/wiki/File:INCRA-router.jpg)DMS' Incra Router Table

The Incra Router Table consists of a large number of separate modular pieces. The following is a partial list of the router table equipment:

- Porter Cable 3.25hp router
- Incra Mast-R-Lift II lift table ([Manufacturer spec sheet/video](https://www.incra.com/router_system_accessories-mast-r-lift-ii.html))([Manual](https://incra.com/manuals/MastRLiftII_Manual.pdf))
- Benchdog cast iron table and stainless cabinet

## Training

[Woodshop 3](https://dallasmakerspace.org/w/index.php?title=Woodshop_3&action=edit&redlink=1) is required before operating specialized Woodshop tools including the router. Prerequisites to Woodshop 3 include Woodshop 1 & 2. Woodshop 4 completes the current sequence of training required for full woodshop tool access.
