Required Materials:

- 6x - 24' 1" 16ga square steel tube (or 12x 12')
  - 10x - 68" cross bars
  - 2x - 70" top cross bars
  - 14x - 25" side supports
  - 4x - 88"
  - [Cut list for 12'](https://dallasmakerspace.org/w/images/0/05/Cutlist.pdf) and [Cut list for 24'](https://dallasmakerspace.org/w/images/5/58/Cutlist_12.pdf)
- 6x - 67.5"x24" sheets of OSB (3x 4'x8' sheets)
