I would like to put our Gnucash transactions into Quickbooks. Quickbooks has some features that will make bookkeeping easier, like automating part of the reconciling process.

## Things That Probably Won't Work

- <http://gnucashtoqif.sourceforge.net/>
  - I tried using older versions of quickbooks.
  - I even took a look at the source code and tried to fix it, but it seems very broken.
  - I was only able to get it to convert the chart of accounts.
- There are several CSV to IIF converters, but they cost \$200 or more.

## What Probably Will Work

- The script I made for the task: <https://github.com/pawl/gnucash2iif/>
