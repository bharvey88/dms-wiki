### Radio

- Software Defined Radio - for use with [GNU Radio](http://gnuradio.org/redmine/wiki/gnuradio)
- Decode some of the non-analog data streams on FM radio
  - build a new down converter: [\[7\]](http://users.skynet.be/myspace/mdsr/DADP/DADP.htm) or [\[8\]](http://users.skynet.be/myspace/mdsr/MFC/DRM_455kHz_to_LF_Converter.htm)
  - try to decode RDS [\[9\]](http://en.wikipedia.org/wiki/Radio_Data_System)
  - maybe try at HD Radio [\[10\]](http://en.wikipedia.org/wiki/HD_Radio)
  - custom software or [GNU Radio](http://gnuradio.org/redmine/wiki/gnuradio)
  - Decoding RDS from an Arduino: [FM Radio Arduino Shield](http://store.curiousinventor.com/fm-radio-arduino-shield.html)
- Experiment with HopeRF modules
  - [RFM22-S2 SMD Wireless Transceiver](http://www.sparkfun.com/commerce/product_info.php?products_id=9581)
  - custom packet protocols
  - use as a constant tunable Local Oscillator for spectrum analyzer or wide-band down converters
  - possibly use with SDR either as tunable oscillator, test signal generator, or whatever
- spy radios
  - two way radios that fit into chapstick tubes
  - use a cell phone earphone/mic head set
  - dial on the bottom of the tube turns radio on and off and adjusts volume
  - take the cap off and plug the headset into an exposed jack
  - button on headset switches between transmit and receive
  - simple to do with just sending morse code, but voice is desirable
  - possibly built into other cool things.
- Web based GNU Radio Transceiver[\[11\]](http://gnuradio.org/redmine/wiki/gnuradio) with USRP1[\[12\]](http://www.ettus.com/products)
- Traffic receiver (from municipal nodes)
- Phased array antenna[\[13\]](http://en.wikipedia.org/wiki/Phased_array)
- APRS node[\[14\]](http://en.wikipedia.org/wiki/Automatic_Packet_Reporting_System)
- Radio telescope (maybe start a hackerspace SETI array)
- Amateur radio link between hackerspaces
