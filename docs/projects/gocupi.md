# Gocupi

!!! note "Source"

Original Design by Brandon Green (brandonAGr) who helped me (Brandon Dunson \| earthtown) build a clone of his machine. His google code page on the project can be found here: <http://code.google.com/p/gocupi/>

If you are installing software from source (i.e. you didn't get a .img file from me) my friend Sarah Hall and I wrote an in depth tutorial to help keep your head above water while installing. It can be found [here](gocupi-software-guide.md) or search for 'gocupi software guide'.
