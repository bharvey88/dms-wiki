# Screen Printing Machine

!!! note "Source"
    Mirrored from [Screen Printing Machine](https://dallasmakerspace.org/wiki/Screen_Printing_Machine) on the Dallas Makerspace wiki (CC BY-SA 3.0).

A screen printing press is a machine used by professional printers to print multiple copies of the screen design on garments in an efficient manner. The machine will be based on the following design: [Four Color Screen Printing Press Plans](http://www.printingplans.com/screenpressplans.pdf)

[![](https://dallasmakerspace.org/w/images/thumb/3/36/Photo.jpg/300px-Photo.jpg)](https://dallasmakerspace.org/wiki/File:Photo.jpg) [](https://dallasmakerspace.org/wiki/File:Photo.jpg)Screen printing machine built by [Emily Owen](http://emilyowenartist.wordpress.com/)
