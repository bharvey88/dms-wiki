Every person that brings a machine gains a 3 day pass for FREE. So if your looking for a project, get started now and reap the rewards of pinball.
  - Vector is coming to VECTOR. Nick Schell found a Vector pinball machine, the machine which inspired the name of the committee. It should be at the DMS in the next week or two. Make sure to come by and see it.
