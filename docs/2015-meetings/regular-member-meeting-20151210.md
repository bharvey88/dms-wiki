- [Infrastructure Committee](https://dallasmakerspace.org/wiki/Infrastructure_Committee)
  - Several laptops and desktops were donated.
    - The laptops have been imaged with the DMS standard Win8.1 image and placed out for general use. The new machines are Intel i5 Gen2, have 4GB RAM, and some have SSDs.
    - The desktops are available to committees upon reasonable request. Please submit a ticket to request one.
      - The vinyl cutter PC has already been upgraded to one of the donated machines.
      - The Science PC has already been upgraded to one of the donated machines.
    - The CAD/CAM PC has been transferred to be the Lasersaur PC.
  - Modified switch uplinks so there is more redundancy between the core and server switches.
  - File server replacement or upgrade is being planned. We will request funding from the board when we have solidified the plan.
    - The new/upgraded server will have expanded storage and increased network bandwidth (\>1 Gbps). It will also have the capability to upload files to AWS for long-term backups.
  - One of the garage doors (the one with the ramp) is broken.
    - Will be requesting funding from BOD to fix and also install an electric opener.
    - The opener will be hooked up to the auxiliary access control system, so not everyone will have access (but will be granted upon reasonable request).
    - An RFID reader will be installed on the outside, but NOT the inside. Inside will have a regular push-button.
    - When the opener is installed, we will post on Talk. You can open a ticket to request RFID access.
  - Camera reorganization in progress.
    - New camera was installed for Amateur Radio. It can see the display on the radio so frequency use can be monitored.
    - Rear warehouse entry camera was relocated for better field of view.
    - One of the Machine Shop cameras was upgraded, and the other one is pending install.
    - Electronics Room camera will be upgraded shortly.
