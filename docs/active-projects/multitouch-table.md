## Introduction

A few people are busily creating an interface for many things using FTIR.

## Project Goals

The Multitouch Table will be able to:

1.  Become a synthesizer
2.  Become a multi-game device that will allow for physical interfaces for the games.

## Project Communication

Through this wiki page. Will try to keep it updated as we progress through the build.

## Status Updates

- 5 December 2012 – Wiki Page started. Project on it's way to completion.
