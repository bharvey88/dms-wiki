## Printing with Roll Paper

Printing on roll media is a little more complicated than standard sized sheet paper. Moreover, mistakes made while printing roll paper can have potentially expensive and wasteful results. Therefore it is important to pay close attention to the various settings when printing. A good approach is to treat it like launching a rocket. Stick to a standard checklist and resist the urge to rush.

## Links, Hints and Tips

Below are some links specific to the printer we have (**Standard Printer: SP7880K3 / Maximum Printer Width: 24" Wide / Ink Technology: Epson UltraChrome K3 with Vivid Magenta**)

NOTE: *When selecting media (paper, canvas, etc...), it's really important to make sure whatever media you select to print on will work with the particular type of ink we use.*

BANDING: Nozzle clogs happen frequently, especially if the printer has been sitting idle for a while. Banding is the result of a clogged nozzle and is usually cleared with a simple cleaning cycle. Press the MENU button and arrow down to TEST PRINT and select NOZZLE CHECK. This will print a stair-step pattern and any missing steps represent clogged nozzles. If you do have some of those then hold down the MENU button for 3 seconds and it will run a cleaning cycle. You can then repeat the test print to see if it's cleared. DO NOT RUN A POWER CLEANING ROUTINE FROM THE MENU! This wastes a LOT of ink.
