This is a list of items we currently need. If you see anything on this list you'd like to donate, bring it by the next [weekly meeting](https://dallasmakerspace.org/wiki/Category:Meetings) or let us know and we can arrange to have it picked up.

For large items, please contact [Andrew LeCody](https://dallasmakerspace.org/wiki/User:Aceat64) before bringing them in, as we have a limited amount of space.

## Equipment/Tools

- Tool kits
- Safety equipment, can never have too much

### Expensive Stuff

- Computer monitors (flatscreens only please, no CRTs)
- Industrial sewing machine
- Air tools
- Woodshop tools:
  - router
  - clamps
  - vise(s)
  - dust collector

- Metalworking shop tools:
  - plasma cutter
  - forge
  - crucible
  - smelter
  - metal "dry" saw
  - metal "cold" saw
  - angle grinders
  - sheet metal (slip) roller
  - box/bending brake/shear
  - sheet metal shear(s)
  - hydraulic press

### Cheaper Stuff

- Hand tools of all kinds:
  - hammer
  - rubber mallet
  - hand saw
  - screwdrivers
  - socket set
  - wire strippers
  - cordless drill
- Pottery tools
  - potter's wheel

## Supplies and Consumables

- 30+ gallon trash bags
- 30+ gallon blue recycling bags
- Paper towels
- Cleaning supplies

  - whiteboard erasable markers

- disposable nitrile gloves
- recordable (or rewritable) CDROM media
  - CD-R/CD-RW media

- safety gear
  - lab safety glasses
  - ear muffs
- shop rags
- printer paper
- lighting (32-watt 48-inch T8 fluorescent tubes)
