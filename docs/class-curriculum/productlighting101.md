## Description

This will be a basic lecture and hands on workshop demonstrating basic lighting principles and how to use them with a range of equipment, starting with the most basic. Bring your own camera's (and manual if you need help with them) and a product you would like to shoot. We may not get to all of them, but a good variety will allow demonstration of how to apply the techniques in a variety of ways.

Class last given on July 11, 2015 between 5:00p-7:00p
