# Robot Combat Interest Group

!!! note "Source"
    Mirrored from [Robot Combat Interest Group](https://dallasmakerspace.org/wiki/Robot_Combat_Interest_Group) on the Dallas Makerspace wiki (CC BY-SA 3.0).

The Robot Combat Interest Group at DMS (Dallas Area Robot Combat or D.A.R.C.) was created to foster invention, creativity and destruction. Members can expect to learn theories and concepts covering DC electronics, AC electronics, mechanics, mechanical design, radio control, material science and physics. This group works under the [Remote Control Committee](https://dallasmakerspace.org/wiki/Remote_Control_Committee)

If you're interested please check out our Facebook page: [Dallas Area Robot Combat Facebook Page](https://www.facebook.com/groups/303491806487599/)
