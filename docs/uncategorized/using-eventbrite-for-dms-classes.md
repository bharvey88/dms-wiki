# Using EventBrite for DMS Classes

!!! note "Source"
    Mirrored from [Using EventBrite for DMS Classes](https://dallasmakerspace.org/wiki/Using_EventBrite_for_DMS_Classes) on the Dallas Makerspace wiki (CC BY-SA 3.0).

This page is being created in an effort to help fill the void of information pertaining to "how do I use EventBrite to charge/advertise for events hosted at Dallas Makerspace?". Paraphrased from [this](https://talk.dallasmakerspace.org/t/eventbrite-discussion-as-it-pertains-to-honorariums/58672/2) Talk post:

Dallas Makerspace Calendar website shows these choices for a class/event:

- Free
- Paid (DMS)
- Paid (Eventbrite)

Free means free.

Paid (DMS) means the registrant will pay through the Calendar page, with funds going to DMS for processing.

Paid (Eventbrite) is the focus here.

When this selection is made, the Calendar then asks for the URL to the Eventbrite event, so **create the EventBrite event first**, then create the DMS Calendar event. [![Eventbrite on dms calendar.png](https://dallasmakerspace.org/w/images/4/48/Eventbrite_on_dms_calendar.png)](https://dallasmakerspace.org/wiki/File:Eventbrite_on_dms_calendar.png)

The submitting instructor will use their own Eventbrite account to set up the event with whatever fee they chose in EventBrite.

The learners will then sign up for the class **on the DMS calendar**, which will then forwarded them to Eventbrite to register and pay.

Those funds will go directly to the Instructor without going through DMS.
