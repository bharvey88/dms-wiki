The CNC embroidery machine is a [Babylock Ellure ESL](http://babylock.com/sewing/previous-models/ellure-ESL/). It has several native fonts and designs. It is fitted with custom software and a card writer to allow it to use custom designs, either purchased or self-programmed using [SewArt64 Digitizer](http://www.sandscomputing.com/id69.html). It was donated by Rebecca and Michael Lass.

Detailed information and curriculum notes are available through the Wiki Tools page, on the [Babylock Ellure](../tools/babylock-ellure-esl.md) page.

There is no cost to use the machine but there is a nominal charge for using the consumables. This is documented in the [Creative Arts Consumables](https://dallasmakerspace.org/wiki/Creative_Arts_Committee) section of the wiki and on the embroidery thread storage box.
