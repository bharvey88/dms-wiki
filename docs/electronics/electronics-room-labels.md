## Proposal

To more easily distribute information and reduce misunderstandings, I propose that we label everything in the electronics room that we can. My proposal is for small labels with a simple description and a QR code that links to the wiki, or a parts database, or both. I've labeled the new multimeters with such labels, printed using the laser printer in the electronics room on some label stock I've donated. A template for the label stock is linked below. I've been using this site to generate the QR codes. <http://www.the-qrcode-generator.com/>
