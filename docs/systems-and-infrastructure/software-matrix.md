## Another Way To List Stuff

Below is a list of the software currently installed on the three computers (3DFAB-01, 3DFAB-02, and 3DFAB-03) in the 3D Fab Room (exceptions will be noted below the list).

In Alphabetical Order (descriptions general copied/pasted from their websites and/or wikipedia):

- **Autodesk 123D Design** ( <http://www.123dapp.com/design> ) - A free, powerful, yet simple 3D creation and editing tool.
- **Autodesk 123D Catch** ( <http://www.123dapp.com/catch> ) - Generate 3D models from photos.
- **Autodesk 123D Make 1.6.0** ( <http://www.123dapp.com/make> ) - Turn 3D models into 2D build plans with animated assembly instructions.
- **Blender** ( <https://www.blender.org> ) - Free and open-source 3D computer graphics software product used for creating animated films, visual effects, art, 3D printed models, interactive 3D applications and video games.
- **Craftware** ( <https://craftunique.com/craftware> ) - \*\* BETA \*\* - A FREE, fast, easy-to-use slicer software that converts your object into a .gcode toolpath format understood by 3D printers.
- **Cura 15.02.1** ( <https://ultimaker.com/en/products/cura-software> ) - \*\* Preferred Slicer for files printed with our PrintrBot Metal Simple 3D printer \*\* - A Free and Open Source 3D model to toolpath Slicer.
- **DesignSpark Mechanical 2.0** ( <http://www.rs-online.com/designspark/electronics/eng/page/mechanical> ) - A free 3D solid modeling and assembly tool that employs a powerful methodology called 'direct modeling' (which is different from parametric-based 3D CAD software).
- **DraftSight 2015 x64** ( <http://www.3ds.com/products-services/draftsight-cad-software/free-download> ) - Straightforward 2D CAD software that’s ideal for students, hobbyists and other individuals.
- **eMachineShop CAD Design Software** ( <http://www.emachineshop.com> ) - Design custom parts with the easy-to-use free CAD software.
- **FreeCAD** ( <http://www.freecadweb.org> ) - FreeCAD is a parametric 3D modeler made primarily to design real-life objects of any size.
- **GWizard Editor and Calc** (<http://www.cnccookbook.com/CCGWizard.html>) - Useful for members engaged in CNC work. For access please post to [Talk Issues and Requests](https://talk.dallasmakerspace.org/c/issues-requests).
- **Houdini FX 14.0.335** (Houdini Apprentice / <http://www.sidefx.com/index.php?option=com_content&task=blogcategory&id=245&Itemid=400> ) - Houdini Apprentice includes all of the features found in Houdini such as modeling, animation, character rigging, lighting, rendering and compositing.
- **Inkscape 0.91** ( <https://inkscape.org> ) - A free and open-source vector graphics editor
- **KISSlicer** ( <http://www.kisslicer.com> ) - \*\* Preferred Slicer for files printed with our PolyPrinter 3D printers \*\* - A fast, easy-to-use, cross-platform program that takes 3D files (STL) and generates path information (G-code) for a 3D Printer. (NOTE: Downloaded from PolyPrinter ( <http://www.polyprinter.com> ) for custom configuration settings)
- **MeshLab** ( <http://meshlab.sourceforge.net> ) - An Open Source system to help the processing of models arising in 3D scanning, providing a set of tools for editing, cleaning, healing, inspecting, rendering and converting of meshes.
- **Meshmixer** ( <http://www.123dapp.com/meshmixer> ) - Tool for 3D mashups and remixes.
- **Netfabb** ( <http://www.netfabb.com/basic.php> ) - Provides mesh edit, repair and analysis of STL files.
- **OpenSCAD** ( <http://www.openscad.org> ) - A software for creating solid 3D CAD objects.

paint.net ( <http://www.getpaint.net/index.html> ) - A free image and photo editing software.

- **Sculptris Alpha 6** ( <http://pixologic.com/sculptris> ) - A fun and engaging way to start off your digital sculpting journey.
- **SketchUp 2015** ( <http://www.sketchup.com/products/sketchup-make> ) - A very easy and free 3D drawing tool.

Exceptions:

- 3DFAB-01 - Needs to have Houdini Apprentice reinstalled.
- 3DFAB-03 (computer near the 3D Scanner) - NextEngine ScanStudio HD Pro ( <https://www.nextengine.com/products/scanstudio-hd/specs/scanstudio-hd-pro> ) - Scanning Software for our NextEngine HD Laser Scanner.
