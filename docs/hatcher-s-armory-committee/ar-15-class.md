# AR-15 Class

!!! note "Source"
    Mirrored from [AR-15 Class](https://dallasmakerspace.org/wiki/AR-15_Class) on the Dallas Makerspace wiki (CC BY-SA 3.0).

**Instructor:** [Andrew LeCody](https://dallasmakerspace.org/wiki/User:Aceat64)

This class will cover the following topics:

- Firearm safety
- History of the AR-15 platform and it's military variants (M16/M4)
- How the AR-15 platform works
- Cleaning an AR-15
- What to look for when buying an AR-15
- How to build your own AR-15

The class is free and open to everyone.
